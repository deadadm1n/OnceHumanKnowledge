# Community Code of Conduct

We want OnceHumanKnowledge to be useful to players of all experience levels.

## Expected behavior
- Be respectful and constructive, especially when correcting a claim.
- Critique evidence and reproducibility, not the person presenting it.
- Welcome newcomers and help them find existing research.
- Credit original researchers and link their work.
- Respect privacy: don't publish private profiles, player IDs, credentials, or unrelated personal information.
- Keep discussions relevant; mark spoilers and scenario-specific information clearly.

## Not acceptable
Harassment, hate speech, personal attacks, threats, doxxing, sexual harassment, spam, repeated bad-faith arguments, or knowingly fabricated evidence. Do not pressure people to install unknown software or reveal account information.

## Enforcement
Maintainers may edit or hide comments, close or lock discussions, reject contributions, or block repeat offenders according to severity. They will consider context and aim for proportional, consistent enforcement.

## Reporting
Use GitHub's report-abuse controls for content that violates GitHub policy. For project-level behavior concerns, contact the repository owner privately through an appropriate GitHub contact channel if one is available; don't publish personal information in a public issue. Security reports follow [SECURITY.md](SECURITY.md).

This is a project-specific conduct policy, not an affiliation with the game's publisher.
