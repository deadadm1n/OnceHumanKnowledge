# Contributing research

Thank you for improving OnceHumanKnowledge! You can contribute even without a GitHub account by suggesting corrections to someone who does.

## Good submissions
1. State the **game version**, **scenario**, server phase, and date observed.
2. Describe the exact item, Deviation, facility, skill or mechanic.
3. Link official patch notes, current tooltip screenshots or repeatable tests.
4. Describe the test setup: gear, traits, buffs, elapsed time, inputs/outputs and number of runs.
5. Show **what changed**, what earlier claim it supersedes, and which page needs an update.

## Evidence checklist
Use labels defined in [docs/EVIDENCE.md](docs/EVIDENCE.md). Prefer released official notes over earlier previews. Multiple guides repeating the same unverified claim are not independent verification.

## Editing conventions
- Use plain English, descriptive headings, and concise tables when helpful.
- Explain abbreviations on first use.
- Record formulas with units, assumptions and test conditions.
- Keep historical corrections in `research/`, not mixed into a current recommendation without warning.
- Link to other topic pages using **relative Markdown paths**.
- Don't commit private account identifiers, location data, screenshots of unrelated personal information or credentials.

## Suggestion template
```text
Claim to update:
Scenario / version / date:
Current behavior:
Evidence (URLs or reproducible test):
Prior conflicting claim (if any):
Confidence and remaining uncertainty:
```

See [open questions](research/open-questions.md) for research tasks.
