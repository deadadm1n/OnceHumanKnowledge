# AI / Agent instructions

This repository is a **retrieval reference**, not a set of authoritative game rules. Start with [README](README.md) and [knowledge index](knowledge/README.md).

## Retrieval workflow
1. Identify the player's **scenario**, **game version/patch**, objective, and available equipment.
2. Open the relevant `knowledge/**/README.md` topic index. Follow links to specific pages; do not rely on the short overview.
3. Read `research/patch-history-audit-2026-10-31.md` and any more recent audits for changes affecting that mechanic.
4. Follow direct source links and distinguish **released patch** from **developer preview** or player report.
5. If sources conflict, prefer the **newest applicable released official patch**; flag ambiguity, especially when actual screenshots disagree.
6. Answer with source URLs or file paths, scenario limits, and confidence. Do not invent precise rates, damage equations, drop chances, or best-in-slot rankings.

## Important anti-hallucination constraints
- `research/` contains working hypotheses, corrected historical mistakes and test plans: these are **not current factual statements**.
- `player-data/` records one person's inventory/observations, **not universal game stats**.
- A number inferred from one player's test must identify its sample size and conditions.
- Dates refer to publication, not necessarily deployment; cross-check before attributing a live behavior.
- Do not casually propose two Key Armor items in one loadout.
- Do not suggest pre-2026 mod reroll mechanics for the new mod system.
- Do not confuse scenario-specific Deviation squads or Cradle mechanics with Isles of Abyss.
- No game memory scanning, automation, exploit development, anti-cheat bypass or unauthorized access is part of this knowledge project.
