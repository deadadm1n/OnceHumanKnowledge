# Help and support

- **Found a wrong fact?** Open a **Mechanics correction** issue with the patch/version and a source.
- **Have a repeatable experiment?** Open a **Research submission** issue.
- **Need a system documented?** Open a **Research request** issue, after searching existing issues.
- **Proposing an edit?** Open a pull request using the provided template.
- **Behavior concern?** Read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- **Security concern?** Follow [SECURITY.md](SECURITY.md), not a public bug report.

This community project cannot troubleshoot account bans, recover accounts, represent the game developer, or guarantee in-game behavior.
