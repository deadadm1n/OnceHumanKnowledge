# Security policy

This repository primarily contains Markdown research and a small validation script. It is not an official game tool or mod.

## Scope
Please report risks involving repository scripts, workflow files, dependency supply chains, malicious links, or exposed secrets. Gameplay balance bugs and inaccurate game mechanics belong in ordinary research issues, **not** security reports.

## Reporting privately
**Do not open a public issue containing exploit details, private keys, tokens, account information, or a working malicious payload.**

If GitHub **Private vulnerability reporting** is enabled, use the repository's **Security → Report a vulnerability** flow. Otherwise contact the maintainer through an established private channel. If no private route is available, open a public issue stating only that you need a private contact method, without sensitive details.

Maintainers will acknowledge reports when available and coordinate safe fixes. No response-time or disclosure deadline is promised.

## Supported version
Only the current default branch is maintained; older snapshots may be retained for historical research.
